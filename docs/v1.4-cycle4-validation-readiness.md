## 2. Dataset design

## 3. Ground-truth methodology

Deterministic checks (arithmetic, extraction, constraints) preferred. Human
adjudication (2 annotators + adjudicator, Cohen's κ) for ambiguous cases.
Ground truth never comes from the model being evaluated. Ambiguous tasks labeled
INDETERMINATE, not forced into correct/incorrect.

## 4. Statistical design

See `research/CYCLE4_STATISTICAL_ANALYSIS.md`. Primary endpoint: risk-weighted
loss at ≥80% coverage. Paired bootstrap (10,000 resamples). Minimum 2000 sealed
tasks for a definitive claim; 500 is a feasibility probe only.
