## Documented versus actual guarantees

- Budget reservation is conservative: worst-case units are reserved for all permitted attempts up front and never refunded.
- Unknown provider usage is now represented as unknown rather than zero.
- The HTTP adapter is OpenAI-compatible only and unverified live.
- Timeout cancellation is cooperative; a late provider response may still incur cost.
- Retry loop retries on transient failures (OSError, timeout, 5xx HTTP) up to `max_attempts` with optional backoff.
- Each retry attempt is accounted for in the total reserved budget.
- Cost units are abstract accounting units, not money.

## Prioritized gaps

1. Live-provider protocol and error behavior: high impact, unverified.
2. Benchmark baselines and fairness: medium impact, implemented in V0.6.
3. CLI exposure: low impact, deferred.
4. Model-output recovery: low impact and out of scope for V0.6.
