# Security review (V0.4)

| Threat | Attack | Defense | Test | Observed | Remaining risk |
|--------|--------|---------|------|----------|----------------|
| Self-granting | agent calls adapter directly / mutates capability rows | adapters require runtime-issued `AdapterContext`; capability transitions happen only in runtime | `test_direct_adapter_use_fails_closed`, `test_malicious_agent_demo` | blocked | in-process agents with debugger access are out of scope |
| Policy tampering | edit crest.yaml to raise E_max or weaken evidence policy | config validation rejects illegal combos; mode is not agent-writable; policy version recorded in audit | `test_config_rejects_illegal_evidence_policy` | blocked | filesystem access to crest.yaml by the *operator* is trusted |
| Receipt forgery | craft/modify receipt payload | payload_digest + evidence_digest + receipt_id binding; Ed25519 signature over canonical payload digest, verified before admission; unknown key/bad signature fail closed | `test_receipt_tampering_any_field_breaks_hash`, `test_tampered_receipt_rejected`, `test_signature_forgery_rejected`, `test_forged_payload_with_valid_digest_but_no_signature` | blocked | an attacker with write access to the DB *and* the private key could still forge; keys are dev-scoped, production custody external |
| Receipt replay | re-present a revoked/expired receipt | revoked flag persisted with capability revocation; TTL; replay after revoke denied even if capability row is reinstated | `test_revoked_receipt_cannot_authorize_even_if_capability_restored` | blocked | a fresh legitimate verification is still allowed, by design |
| Stale evidence | keep executing after environment changes | drift checks (family topology, pinned-target sha256/size/type/symlink identity, content digest) + per-execution reprobe + expiry | `test_drift_*`, `test_content_modification_triggers_content_drift`, `test_target_replacement_triggers_identity_drift`, `test_revoked_receipt_cannot_authorize_even_if_capability_restored` | partially covered: scope/permission/environment drift undetected | unpinned rename/move drift is invisible unless evidence was admitted with `pinned_target` |
| Fixture overfitting | recovery keyed to verifier artifacts | independent holdout generator + distribution shifts; failures ⇒ UNVERIFIED | `test_overfit_on_tree_family_passes_in_distribution_but_fails_holdout`, ablation | rejected | adversarial learners with new strategies may still fool fixtures |
| Verifier gaming | recovery detects test harness | adversarial distribution re-injects artifacts (so gaming fails to help), adversarial gate still scored 1.00 there | cross-distribution experiment | partially detected | deeper gaming (e.g., timing, resource probing) untested |
| Scope escape | `..`, absolute paths, UNC, symlinks, case tricks | canonicalization + workspace containment; scope glob matching | `test_path_traversal_blocked`, `test_path_type_change_detected` | blocked | Windows junctions created by privileged actors not covered |
| Adapter bypass | call FilesystemAdapter/GitAdapter without context | context required and non-forgeable outside runtime | `test_direct_adapter_use_fails_closed` | blocked | none known |
| TOCTOU | swap target between check and use | target re-canonicalized and scope re-checked immediately before dispatch | `TOCTOU_WORKSPACE_VIOLATION`, `TOCTOU_SCOPE_VIOLATION` paths | mitigated, not eliminated | residual window between re-check and syscall |
| Concurrency | race admission against the budget | ledger reservation under runtime lock; SQLite WAL | `test_concurrent_budget_race` | blocked | multi-process runtimes would need DB-level locking |
| Crash consistency | crash before/after execution, during revocation | durable ledger + revocation; restart keeps revocations and exposure | `tests/security/test_v04_integrity.py` (crash tests) | blocked | power-loss during SQLite commit relies on SQLite durability |
| DB corruption | corrupt or downgrade the state file | schema_version check, migration history, fail-closed errors, doctor | `test_future_schema_version_fails_closed`, `test_corrupt_database_fails_closed` | blocked | doctor reports, runtime refuses |
| Secret leakage | tokens in arguments/audit/CLI | redaction on audit paths and CLI output | `test_audit_does_not_store_secrets`, `test_redaction_masks_common_secret_shapes` | mitigated | best-effort patterns, not a scanner |
| Evidence mislabeling | V0.3 conflated "failed generalization" with fixture evidence | V0.4: any observed failure ⇒ UNVERIFIED | `test_observed_failure_never_yields_authority` | fixed | policy thresholds remain a judgement call |
